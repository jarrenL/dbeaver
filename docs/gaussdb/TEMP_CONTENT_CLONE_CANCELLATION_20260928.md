# 临时内容复制取消保护

日期：2026-09-28。历史场景 9.8 数据编辑/副本、1.6 取消及资源、11.1 大对象。

正式平台模块新增 TemporaryContentStorageTest，共三个场景：正常复制、复制开始前取消、复制首块后取消。使用真实 100003 字节文件、独立副本目录及生产 cloneStorage，平台与进度监视器为替身。验证原文件完整、副本完整、字符集保持、源存储 release 不删除外部原文件、副本 release 删除自有文件。

两个取消场景红测均失败：copyStreams 取消时直接返回，cloneStorage 将空文件或部分副本当作成功结果。

修复在创建临时文件前检查取消，并在复制返回后再次检查；抛取消 I/O 异常，由既有失败清理路径删除副本。两场景验证失败目录为空、原文件不变、同一源对象解除取消后重试完整复制。只操作 JUnit 专用文件。
