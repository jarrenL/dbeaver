日期：2026-09-28。历史场景 1.6 取消及资源、11.1 BLOB/XML 类型。

正式平台测试新增五项：BLOB 内存/文件首次读取前取消、BLOB 内存流关闭时取消；XML 首次读取前取消、Reader 关闭时取消。红测五项均失败。文件分支此前有复制后检查，但已取消时仍会访问 Blob；内存及 XML 路径未拒绝取消。
