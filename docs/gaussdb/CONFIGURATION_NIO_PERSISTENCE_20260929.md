## 边界

- 环境为本机 macOS，不作为 Windows ACL、麒麟权限或远程文件系统验收。
- 目录冲突是可控的真实文件系统失败，不等于磁盘满、写入中断、断电或写入部分字节。
- 备份仅验证本次执行的当日行为，未验证跨日策略。
- 没有经过连接向导或实际数据库连接，不证明主配置和凭据两个文件的原子提交。
- 只操作独立临时目录，不访问现有工作区连接配置。
