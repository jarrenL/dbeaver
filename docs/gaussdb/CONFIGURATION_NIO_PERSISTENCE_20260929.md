2. 关闭保存密码后重新保存；实际凭据文件仍有用户名，但不再有密码。
3. 删除最后一个认证配置再保存；当前凭据文件在磁盘上消失，管理器读取为空，原内存配置未被清空。
4. 检查当日备份仍与首次写出的加密凭据字节一致，且能够用测试密钥解密得到原密码。
