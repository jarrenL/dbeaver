# 批量包编译：部分诊断、取消与结果快照

## 新增8项

生产GaussDBPackageCompileBatch调度器使用可注入Compiler回调验证，不连接数据库：

- ALL、SPECIFICATION、BODY各自覆盖普通失败和失败同时取消（6项）。第一个包生成诊断，第二个包先生成两条诊断再抛DBException，第三个包不得执行。核对completed=1、total=3、停止对象、原始异常、独立取消标志及三条诊断的对象归属和顺序。两个对象名称相同，不能按名称错误归并。
- 第一个包执行完并报告进度后取消（1项）。保留completed=1，第二个包作为停止位置，但不调用其Compiler，不把未处理对象算作完成。
- 结果列表快照（1项）。修改原始列表不改变结果，结果诊断列表不能被外部清空。这只验证列表独立性，不宣称深拷贝了包或诊断对象。

## 验证方式与范围

直接运行生产批处理循环，模拟编译回调负责控制错误和取消时刻；测试观察实际调用顺序、进度计数和结果记录。本轮未修改生产实现，不将模拟的编译结果算作真库编译通过。
