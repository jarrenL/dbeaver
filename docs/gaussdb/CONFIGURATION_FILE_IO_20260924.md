# 配置文件管理器实文件验证

## 范围

对应历史清单 3.12、10.3、10.4。直接使用生产 `DataSourceConfigurationManagerNIO`，只模拟项目目录定位，其余采用 JUnit 临时目录内真实文件操作。全部内容是虚构数据，不操作用户连接文件。

## 十一项场景

| 场景 | 数量 | 操作与检查 |
| --- | ---: | --- |
| 写入、覆盖和备份 | 1 | 中文与扩展汉字内容逐字节读取；覆盖后读新内容，备份保留旧内容；检查管理器属性 |
| 缺失文件 | 1 | 返回 null |
| 旧格式路径读取 | 1 | 从项目根目录读取旧配置 |
| 路径优先级 | 1 | 元数据目录与项目根目录同名时读取元数据版本，根目录副本不变 |
| 清空配置 | 2 | null 和零字节各一项：删除指定文件、保留备份和无关文件、重复清空不报错 |
| 新格式枚举 | 1 | 枚举默认及额外配置，忽略备份、目录和旧格式文件 |
| 旧格式枚举 | 1 | 无新格式文件时发现旧格式默认配置 |
| 空项目枚举 | 1 | 提供默认配置描述，不实际创建文件 |
| 删除失败 | 1 | 目标被非空目录占用时必须报告 IOException，目录中哨兵文件不变 |
| 写入失败 | 1 | 同类非法目标写入报 IOException，哨兵文件不变 |

## 缺陷与修复

`run-9pOeOF` 删除失败测试未收到预期异常，其余十项通过。实现捕获删除 IOException 后仅输出 debug 日志，导致调用方无法知道删除没有生效。

替换为 `Files.deleteIfExists`：目标不存在仍视为无须操作；实际删除失败向调用方传播。未引入递归删除，也不改变备份命名。

## 未覆盖边界

本轮运行于本机文件系统，不是 Windows 权限、网络盘或断电测试。备份策略按同一天保留已有备份，备份失败目前可能仅记录日志；普通写入尚未通过崩溃原子性测试。未验证 GUI 保存结果提示，不能把底层异常传播等同界面已提示。

## 结果

### 备份保留和序列化实文件追加验证

追加六项：

- 同一天连续覆盖，备份保留第一次被替换的内容。
- 将测试备份时间设为两天前，下一次写入将备份更新为本次覆盖前内容。
- 点号开头的文件采用单个前导点备份名称，不增加第二个点。
- 删除配置后，以保留备份内容重新写入，可逐字节恢复。
- 明文/加密两种路径各一项：调用生产 `saveConfigFile`，经真实 NIO 管理器落盘，再由新序列化器/加密器实例调用生产 `loadConfigFile` 恢复中文、扩展汉字和虚构密码；加密落盘不含该测试密码明文，删除后备份仍可解密恢复。

最后两项通过反射调用生产内部文件方法，未执行完整 `saveDataSources` 对象序列化，不等同于 GUI 密码开关或系统钥匙串验证。明文是方法的显式非加密分支，不表示普通凭据文件默认明文保存。

**删除范围说明：**删除主凭据文件仍会留下可恢复备份。这些通过结果只证明当前备份/恢复行为，不代表密码全部副本已清除，也不代表备份加密具有认证防篡改能力。全量秘密清理策略需明确后单独验收。

追加六项均通过，未修改生产代码。`run-W4sBOj` 整套新鲜结果1493项、1469通过、24跳过、零失败/错误；临时授权角色已删除。[备份和实文件序列化脱敏报告](test-results-20260924-configuration-backup.json)。

`run-Xbw7bd` 新增十一项全部通过；整套新鲜结果1487项、1463通过、24跳过、零失败/错误。跳过不算通过，本次跳过代码格式检查；临时授权角色已删除。[脱敏逐例结果](test-results-20260924-configuration-file-io.json)。
