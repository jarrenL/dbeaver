# 配置文件管理器实文件验证

## 范围

对应历史清单 3.12、10.3、10.4。直接使用生产 `DataSourceConfigurationManagerNIO`，只模拟项目目录定位，其余采用 JUnit 临时目录内真实文件操作。全部内容是虚构数据，不操作用户连接文件。

## 十一项场景

| 场景 | 数量 | 操作与检查 |
| --- | ---: | --- |
| 写入、覆盖和备份 | 1 | 中文与扩展汉字内容逐字节读取；覆盖后读新内容，备份保留旧内容；检查管理器属性 |
| 缺失文件 | 1 | 返回 null |
| 旧格式路径读取 | 1 | 从项目根目录读取旧配置 |
| 路径优先级 | 1 | 元数据目录与项目根目录同名时读取元数据版本，根目录副本不变 |
| 清空配置 | 2 | null 和零字节各一项：删除指定文件、保留备份和无关文件、重复清空不报错 |
| 新格式枚举 | 1 | 枚举默认及额外配置，忽略备份、目录和旧格式文件 |
| 旧格式枚举 | 1 | 无新格式文件时发现旧格式默认配置 |
| 空项目枚举 | 1 | 提供默认配置描述，不实际创建文件 |
| 删除失败 | 1 | 目标被非空目录占用时必须报告 IOException，目录中哨兵文件不变 |
| 写入失败 | 1 | 同类非法目标写入报 IOException，哨兵文件不变 |

## 缺陷与修复

`run-9pOeOF` 删除失败测试未收到预期异常，其余十项通过。实现捕获删除 IOException 后仅输出 debug 日志，导致调用方无法知道删除没有生效。

替换为 `Files.deleteIfExists`：目标不存在仍视为无须操作；实际删除失败向调用方传播。未引入递归删除，也不改变备份命名。

## 未覆盖边界

本轮运行于本机文件系统，不是 Windows 权限、网络盘或断电测试。备份策略按同一天保留已有备份，备份失败目前可能仅记录日志；普通写入尚未通过崩溃原子性测试。未验证 GUI 保存结果提示，不能把底层异常传播等同界面已提示。
