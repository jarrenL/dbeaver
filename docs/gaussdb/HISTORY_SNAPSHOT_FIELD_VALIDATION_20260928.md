# 历史快照字段完整性验证

日期：2026-09-28。对应历史清单 3.11 的持久化、加载异常与历史内容保护。

## 发现及修复

`QueryHistoryStore` 原先直接将 JSON 反序列化为记录。字段类型错误时，部分值被转换为字符串或数值，之后的非空、时间先后检查不足以识别损坏记录。

10 项损坏字段测试首次执行有 7 项未按预期拒绝（联合 677 项中 670 通过、7 失败）。涉及数字/布尔型 SQL、数字项目 ID、布尔错误文本、超范围结束时间、字符串时间与字符串事务标记。其余 3 项此前已拒绝，不能算新增缺陷。

修复为先检查 JSON 结构、必需文本类型、起止时间和其他已提供数字的整数范围、事务标记类型，再构造记录。数值范围使用精确转换检查，不通过截断或浮点近似接受越界值。版本号也必须是 int 范围的整数数值，之后继续校验支持的版本。异常不包含解析 cause 或 SQL 原文，损坏文件原样保留。

可选字段缺失或空值的既有默认语义及未知字段忽略行为保留；正常生产写入格式不变。该修复不自动修复损坏文件，不声称提供文件签名或防恶意篡改功能。
