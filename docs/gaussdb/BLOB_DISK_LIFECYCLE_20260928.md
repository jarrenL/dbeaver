# BLOB 临时文件取消回归

日期：2026-09-28。历史场景 1.6 流异常/取消、11.1 BLOB 二进制。

正式平台测试 JDBCContentBLOBReadTest 新增四项：正常分段读取、读取失败、关闭失败、复制中取消。生产 JDBCContentBLOB 显式编译，内存阈值设为 0，使用真实 JUnit 专用临时目录和输出文件。JDBC Blob 和监视器为替身，输入为真实内存流包装，257 字节覆盖全部字节值，每次最多返回 7 字节。

正常与读取/关闭失败场景原实现通过，说明源流原本已有正确关闭。仅取消场景红测失败：复制工具取消时返回，BLOB 调用方仍发布部分文件缓存。

修复在复制返回后检查取消，抛 InterruptedIOException，经原有错误路径关闭资源并清理临时文件。测试验证异常类型、目录为空、原 Blob 未 free；同对象解除取消重试后文件字节完全一致。成功时缓存复用，释放存储后文件删除。
