# 查询历史持久化运行时接入

对应历史清单 3.11。存储、映射和生命周期层已接入实际注册器、首选项与默认历史浏览器；本页不作为 GUI 重启验收报告。

## 使用入口与数据范围

查询管理首选项新增“重启后恢复查询历史（将 SQL 保存到工作区）”，默认关闭，与文本日志开关分开。提示 SQL 和错误信息可能包含敏感值，关闭不会删除已有文件。最多保留 2000 条完成查询，使用配置的保留天数；只启用历史持久化时也可编辑保留天数。

快照位于工作区元数据目录 `query-history.json`，与具体数据库无关。用户需主动开启；开启前的查询不会追溯写入。采用查询管理既有事件类型/用途过滤器；现有连接日志禁用、空查询、取数中及已删除状态继续参与过滤。

默认全历史浏览器合并持久化事件与本次内存事件，同一当前对象不重复追加；当前会话浏览器不加载旧记录。历史读取错误显式显示，不伪装为空列表；持久化删除失败不继续删除内存记录。错误标题和首选项提供中英文文案。

## 关闭与开关边界

注册器退出时在注销持久化服务前保存 collector 快照。快照覆盖历史列表、正在分发和等待分发事件，不消费事件池、不截断其他监听器通知；仅映射器认可的已完成查询落盘。后台分发与关闭保存通过服务同步协调。

关闭记录后，当前进程已加载的持久化历史仍响应明确删除操作，防止重新开启后复活。关闭本身不删除历史文件；已有保存的 SQL 内容仍需按保留期或明确删除操作管理。

## 本轮验证

晚到首选项通知补验：`disposedServiceCannotBeReenabledByAlreadyQueuedPreferenceNotification` 在 `run-YRdCCp` 先复现关闭后的服务被开启通知重新激活，记录新的查询。新增终态保护后，晚到通知被忽略、重复关闭仅移除一次监听器。完整回归 `run-LAvxxH`：1666 项，1643 通过、23 跳过、0 失败/错误，见 `history-dispose-guard-results-20260924.json`。这是确定回调顺序测试；尚未将该终态保护安装至 GUI 验收副本，不声称实际并发队列压力测试通过。

2026-09-24 退出边界补验：`QueryHistoryPersistenceServiceTest` 新增三项，通过生产 `QMRegistryImpl.dispose()`、collector 快照和真实临时文件验证待分发已完成查询落盘、重复关闭不重复记录、活动/已删除查询及关闭后的晚到回调不写入、未开启持久化时不建文件。collector 后台任务销毁被替换，不启动 Eclipse 后台线程；这是确定时序的组件测试，不代表强杀、断电或 GUI 极短退出窗口已验证。完整回归 `run-6byozE`：1665 项，1642 通过、23 跳过、0 失败/错误；机器可读结果见 `history-shutdown-results-20260924.json`。

- 运行时服务：显式开启、不追溯旧查询、重建服务后读取及删除、损坏文件保留并向浏览器传播错误。
- collector：待分发与分发中的事件均包含在退出快照，不消费通知，分发完成后不重复留在 in-flight 列表。
- 默认浏览器：持久化/内存对象合并去重和时间排序，当前会话隔离，读取错误及删除失败传播。
- 关闭记录后的明确删除不因重新开启而复活。
