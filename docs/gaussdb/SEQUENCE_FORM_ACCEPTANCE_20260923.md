# 序列属性页能力控制验证

环境：Linux GTK 隔离客户端，GaussDB 507 分布式，普通测试账号。客户端更新 UI 插件至 5.1.200.202609231501。

## 缺陷与修复

属性编辑器此前只判断对象是否注册重命名管理器，没有调用管理器的 `canRenameObject`。即使序列元数据声明不能重命名，名称输入框仍可编辑。修复为创建名称控件及提交名称修改时都检查对象重命名能力。

## 真实界面结果

| 场景 | 操作及断言 | 结果 |
|---|---|---|
| 修复前复现 | 打开测试序列属性页，读取名称输入框 SWT editable 属性 | true，确认缺陷 |
| 修复后名称只读 | 同一对象重新打开，名称控件仍显示正确名称，editable=false | 通过 |
| 不影响其他属性 | 描述框 editable=true；输入描述后编辑器出现未保存标记、保存按钮启用 | 通过 |
| 撤销恢复 | 点击撤销并确认，描述恢复为空，保存按钮禁用；独立数据库查询注释未修改 | 通过 |
| 最后值限制保留 | 最后值控件 editable=false | 通过 |
| 重命名菜单 | 当前诊断仍记录主菜单 enabled=true，尚未确认菜单显示时的动态刷新行为 | 未闭环，不计通过 |

界面队列证据：475（修复前）、480–488（修复后）。完成后删除本轮专用序列，系统目录确认剩余数量为 0。关闭菜单操作未观察到编辑器消失，保留未修改的旧对象页，不计关闭操作通过。临时授权测试角色已删除。其他测试对象保留。

本轮自动化回归 1006 项：982 通过、24 跳过、0 失败/错误，见同目录 `test-results-20260923-form-rename-gate.json`。跳过不计验收通过；本报告不是全部历史清单完成声明。
