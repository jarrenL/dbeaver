# 认证配置损坏记录与运行时凭据保护

对应历史清单3.12/3.13/10.3。显式编译DBAAuthProfile及其DBPConfigurationProfile父类，使用模拟DBSSecretController返回合成凭据记录，不访问用户真实密码。

## 场景和修复

新增七种非法记录：JSON null、数组、用户名数组、密码对象、properties数组、嵌套属性对象、包含合成敏感标记的截断JSON。红测`/tmp/shared-auth-secret-red-20260928.log`408项中401通过、7失败：部分错误值被转换/清空，解析异常也未按DBException边界处理。

修复先确认记录是对象、用户名/密码是字符串或null、扩展属性是字符串/null值映射；完整转换后才替换运行时字段。解析失败统一使用不回显原文的DBException，不附加可能包含记录内容的JSON解析异常。存储控制器本身抛出的DBException仍按原路径传递。

每个负例验证用户名、运行时密码、扩展属性不变，完整异常堆栈不含合成敏感标记；同实例改为有效记录后再次读取成功，无写入或刷新操作。另增两个正例：空对象及显式null字段对象仍可清空运行时凭据，保留savePassword选项。缺失记录与明确空对象行为有区别，原缺失记录测试继续保留。

## 验证结果及范围

AuthProfileSecretStorageTest共19项（原10＋新增9），包含原有保存密码选项、写/刷新/读失败、记录隔离等。联合`/tmp/shared-auth-secret-final-20260928.log`410/410通过、0跳过、0失败；原391项复跑，不叠加计数。新增正式必需类门控，其验证器7/7通过，属于测试基础设施自测。

这里处理的是凭据控制器返回的记录内容，不验证其磁盘加密、密钥管理、系统凭据库或文件权限。未覆盖GUI认证配置导入、所有旧版本数据迁移、实际OS安全存储、重复JSON字段及并发配置更新，不作为全面安全审计结论。完整构建/真库/GUI环境验收仍未完成。
