# BLOB 内存缓存关闭失败重试

日期：2026-09-28。历史场景 1.6 I/O 异常及资源、11.1 BLOB 类型。

JDBCContentBLOBReadTest 新增四项：正常读取、读取错误、缓存工厂关闭输入流失败、调用方外层关闭输入流失败。生产缓存工厂本身会关闭流，调用方仍有 try-with-resources；本轮不改变这一既有关闭行为，分别注入两个关闭阶段的故障。

红测四项中前三项通过，外层关闭错误后的重试失败：原代码在外层流关闭前已赋值 storage，虽然向调用方报错，下一次 getContents 却直接复用了旧缓存，未重新读取替换后的 Blob。

修复使用局部存储变量，外层资源成功关闭后才赋值到对象缓存。测试核对实际异常原因、不提前 free、同对象重试再次打开流并读到不同的新字节、缓存复用及最终只 free 一次。源为内存流故障包装，Blob 为 JDBC 替身，不是厂商实机故障。
