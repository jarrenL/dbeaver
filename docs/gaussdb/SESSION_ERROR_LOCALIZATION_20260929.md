# 会话错误提示：中英文资源覆盖

对应历史清单DS_auto个性化/语言设置的客户端资源层，不代替语言切换GUI验收。

## 修改与验证

近期会话标识校验和NULL检测使用了硬编码英文错误，本轮改为PostgreSQLMessages资源字段，新增默认英文和简体中文翻译：

- session_invalid_identifier：服务器会话标识无效。
- session_identifier_null：服务器返回的会话标识为NULL。
- 既有session_operation_not_confirmed同时纳入资源检查。

新增2项测试分别读取插件实际资源路径的默认及_zh properties，核对三个键非空、对应语言文本及NLS声明/加载值；旧实现两项因缺少键失败，修复后2/2通过。既有9种无效编号测试增加异常消息必须引用NLS字段的断言，所在Identity类15/15通过。SQLSTATE 22004和原始异常传播策略未变。

未修改JVM默认Locale或模拟界面切换，因此不能将资源存在表述为Help菜单切换语言或最终安装包显示已验收；数字解析的底层技术cause仍可能包含英文。

## 回归结果

73模块中五个测试模块2705项：2530通过、174跳过、0失败、1错误（RestTest网络权限拒绝）。独立门禁拒绝整体验收；门禁自身7/7。新资源类已列入必跑。本轮没有真库、GUI或安装包发布结论，未推送远程。

日志：`/tmp/session-nls-red-20260929.log`、`/tmp/session-nls-green-20260929.log`；[脱敏逐项结果](evidence/SESSION_NLS_REACTOR_20260929.json)。

## 辅助审核可用性

只读检查本机辅助审核程序的CLI帮助、日志初始化及默认配置源码，未发现仅重定向日志目录的CLI参数；现有logging配置只提供级别/大小/保留份数。底层函数虽能传入不同home，但当前CLI没有把它作为独立日志路径选项暴露。不修改受限安装/配置目录，不搬运认证信息，本轮没有产生新的辅助审核报告。
