# 转义引号及名称末尾点号验证

历史清单映射：1.4 字符串/标识符转义、6 解析工具、8 名称解析、9.5 对象搜索。

## 复现及修复

`SQLUtils.splitFullIdentifier` 原先把双写的结束引号当作组件结束，将 `"a"".schema"."table"` 拆成三个组件；去引号时还将 `"schema."` 的末尾点号误删。新增测试先在 `run-XCpv5h` 中复现两项失败。

修复扫描时跳过双写结束引号；保留引号模式不改动转义文本，去引号模式还原名称中的单个引号。组件内部末尾点号不再被删除。单组件与多组件采用相同扫描路径，未闭合的转义前缀也保持完整。

## 测试方法

- `SQLUtilsTest`：转义引号与内部点号、名称末尾点号、单组件、未闭合组件；双引号/反引号/方括号；保留引号与去引号输出分别断言。
- `GaussDBHistoricalJdbcLiveTest.splitQualifiedIdentifiersMatchRealCatalogNames`：两种部署分别在隔离 schema 中创建 `a".table`、`table.`、`研发.表`、`space . name`，插入整数7；由生产方言生成限定名称，生产拆分工具得到schema/表名，生产搜索路径读取真实目录并精确匹配；重新引用拆分结果查询，必须恰好读回一行7。隔离schema由公共测试清理器回收。

首轮修复回归 `run-hZ5OwO` 为1523项、1500通过、23跳过、0失败/错误，尚未包含最后新增的双拓扑测试。最终结果另行记录。

边界：本轮不等同GUI补全弹窗验收，不证明所有数据库方言的反斜杠转义规则。服务器专属、可选环境及其他未执行项不计入通过；不以测试数量作为内网历史用例覆盖率。
