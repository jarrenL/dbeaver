# 查询历史删除：底层修复进展

对应历史清单3.11删除/清理。GUI中已复现删除后刷新复现，见QUERY_HISTORY_GUI_20260924.md。本页为实现进度，不是完整GUI验收报告。

## 底层实现

`QMMObject`新增仅会话内、transient/volatile的历史删除状态；它不删除数据库数据、SQL脚本或日志文件，也不是永久磁盘擦除。

`QMMCollectorImpl.deleteHistoryObjects`在历史锁内标记目标对象并移除对应旧事件；获取历史快照及后台分发追加时也排除已删除对象。状态随元数据对象持有，不额外维护不断增长的全局对象编号集合。同一对象的多个事件一起移除，其他对象不受影响。

## 已添加测试

`QueryHistoryCollectorTest`调用真实生产方法，通过可控分发周期验证：

- 同一对象BEGIN/END均移除、另一对象保留；重复删除幂等。
- 在监听回调中删除（历史追加之前的交错），不得被随后追加回来；后续相同对象事件也不恢复。
- 对仍在待分发池的对象删除后不进入历史；新对象的后续查询正常进入，空集合删除不影响它。

测试使用Mockito构造元数据和监听器，但调用实际分发与删除代码；这是确定性交错，不是多线程高负载压力测试。
