# 包编译源码行号换算边界

## 对应需求及新增6项

对应编译错误定位，直接调用生产GaussDBPackageSourceLines.toEditorLine：

- 目录内容行号为Integer.MIN_VALUE、-1、0（3项），分别检查源码缺失和存在CREATE头的情形，必须回退合法的第1行。
- 正数行号加源码头偏移发生整数溢出（1项，含两种偏移），不能变成负数；未溢出的边界值保持原映射。
- 嵌套块注释、含双引号转义的包名与AS/IS字样（1项），这些字样不能被误认作源码头结束符。
- 正文开始处的多行空行（1项），不能被额外当成源码头偏移重复计算。

## 发现与修改

红测9项中4项失败：3种无效行号原样返回，极大正数加偏移溢出为-2147483648。其余词法和空行场景原本通过。日志：`/tmp/package-source-lines-red-20260929.log`。

修改仅为非法非正数回退第1行、使用long中间值计算偏移并对超出编辑器int行号范围的结果回退。正常CREATE头解析及正文坐标语义不变。这里第1行表示安全回退，**不声称是准确错误位置**。

完整结果见[逐项证据](evidence/PACKAGE_SOURCE_LINES_REACTOR_20260929.json)，回归日志：`/tmp/package-source-lines-green-20260929.log`。测试类加入必跑清单。

最终SourceLines类**9/9通过、零跳过**。73模块中五个测试模块合计**2638项：2464通过、173跳过、0失败、1错误**。唯一错误仍为RestTest本地网络权限拒绝，独立门禁拒绝整体通过；门禁自测7/7。诊断构建仅允许继续收集后续模块结果，不将构建SUCCESS或跳过当成验收通过。本轮没有真库或GUI新增通过结果。

## 边界说明

本轮为源码字符串和目录坐标转换的单元测试；不证明服务端会产生上述异常数据，不代替集中式ORA真库或编辑器双击跳转验收。源码文本的所有语法形式、错误位置超过实际文档长度时的UI行为，仍需要其他层验证。
