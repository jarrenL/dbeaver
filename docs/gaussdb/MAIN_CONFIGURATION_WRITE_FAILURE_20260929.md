# 主配置写入失败与凭据隔离验证

## 范围

对应历史清单中的连接配置持久化、保存异常与恢复。与内存 JSON 序列化失败、凭据文件写入失败分别验证，本轮没有修改生产代码。

## 存储接口异常

新增 `ConfigurationReadFailureTest.mainConfigurationWriteFailureMustNotAdvanceCredentials` 四项，覆盖普通/加密项目 × `IOException`/`DBException`。使用真实主保存器和加密器，文件管理器模拟在写主文件前拒绝：

- 原始异常对象传播；不调用凭据写入。
- 模拟存储中已有主配置与凭据字节不变，内存密码不变。
- 同一保存器显式重试后主文件合法、加密项目可解密，中文名称恢复，主 JSON 不含测试密码；凭据输出含对应配置 ID 与密码。
- 主文件调用两次，凭据只调用一次。

接口测试配置类 63/63 通过，日志 `/tmp/config-main-write-20260929.log`。不据此声称物理文件部分写入可回滚。

## 真实 NIO 主文件路径冲突

在已有两项普通/加密项目磁盘往返测试中增加断言，不额外增加测试计数：

1. 首次真实保存后，将主配置移至保留路径，在原路径创建含子文件的目录。
2. 修改认证配置描述，真实完整保存器写入失败，要求 `IOException` 传播。
3. 检查保留的原主文件逐字节不变、活动凭据逐字节不变、冲突目录子文件及内存密码不变。
4. 将冲突目录整体移动保留，同一保存器重试；用真实解析器从磁盘加载，确认新描述和原密码正确，原文件及目录子文件仍保留。

测试限定专用临时目录，未删除用户文件。真实写入失败是非空目录冲突，不是磁盘满、断电、并发写、Windows/Linux 文件权限或两个文件的原子提交。注册表为替身，不代表 GUI 错误提示验收。

首次真实文件测试扩展因局部变量与已有循环变量重名而编译失败（`/tmp/config-main-disk-20260929.log`），未计为产品缺陷或测试通过。修正测试变量名称后重新完整执行，复验日志 `/tmp/config-main-disk-pass-20260929.log`。诊断构建允许后续模块继续收集，整体结论须看逐项报告及独立门禁。

最终配置类 **63/63**、真实 NIO 类 **8/8** 通过，均零跳过。73 模块诊断共 2530 项：2360 通过、169 跳过、1 Rest 网络权限错误，独立门禁拒绝。两项 NIO 扩展仅增加断言，不新增计数。逐项结果见 [回归证据](evidence/MAIN_CONFIGURATION_WRITE_REACTOR_20260929.json)。
