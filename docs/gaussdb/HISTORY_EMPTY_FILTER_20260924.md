# 查询历史空记录过滤与持久化核对

对应历史场景清单 3.11：历史列表、内容过滤及持久化。下述过滤修复不等同于持久化完成。

## 发现与修复

`QMRegistryImpl.DefaultEventBrowser` 未应用 `QMEventCriteria.skipEmptyQueries`。仅开启这一条件且没有类型/文本/自定义过滤时，也不会进入过滤分支。

新增两项生产浏览器回归：

- 开启条件后排除 null、空字符串及空格/制表符/换行查询；保留真实 SQL，包括字符串常量中的空格与中文，不能改写原 SQL。
- 默认不开启时保留空查询；开启后仍保留没有 SQL 文本的连接事件，不能误删非查询事件。

run-dDpdCL：1632 项，1607 通过、23 跳过、2 失败，均为新增回归。修复后 run-pylpk6：1632 项，1609 通过、23 跳过、0 失败错误。回归验证的是生产浏览器及游标，事件来源模拟；没有把该结果记为 GUI 或持久化验收。专用权限测试角色在结束时清理。

## 跨重启历史的当前缺口

代码核对：默认浏览器从 `QMMCollectorImpl.getPastEvents()` 读取内存列表；`QMLogFileWriter` 输出文本日志，没有对应加载进入默认浏览器的逻辑。`getEventBrowser(false)` 可适配其他实现，但不能据此声称当前产品已有持久化提供者。此前 GUI 重启后历史为空与此一致。

后续实现须同时验证：独立持久化提供者、当前会话与历史会话隔离、查询及连接身份重建、成功/失败结果重建、中文多行 SQL、删除后重启不复活、保留期与容量限制、损坏/中断写入恢复、异步加载取消、关闭刷盘、禁用记录与敏感命令保护。文本日志输出不能替代这些验收；不得默认将凭据或所有连接配置序列化到历史文件。
