## 发现和修复

原实现没有读取 `version`，因此不兼容版本及缺失版本共4项失败（run-YP9SJ7）；其余8项通过。更早一次运行是测试代码类型编译问题，不计作产品失败。

生产修复仅在 PostgreSQL 计划读取入口校验当前格式版本1；不改变文件写入格式，不替代其他数据库驱动的版本策略。不兼容文件向既有上层错误处理返回异常，而不是按当前格式猜测解析。

## 并行节点及扩展格式增补

新增4项：并行节点连续保存/加载3次仍仅保留一个 `Parallel` 前缀；多根节点顺序与未知节点扩展属性（含中文）往返保留；空根列表仍为空；原始XML的Parallel-Aware节点仍正确添加显示前缀。

run-nLjV1Y 的保存文件测试15项中1项失败，实际为 `Parallel Parallel Sort`，另14项通过。根因是序列化存入已带显示前缀的类型，反序列化时又根据Parallel-Aware重复添加。修复共用节点模型为仅在尚无前缀时添加，未移除Parallel-Aware属性。XML正向回归防止修复导致原始并行节点失去标识。

修复后run-WVtB4d：1509项，1485通过、24跳过、0失败/错误。新增4项均通过。详见`test-results-parallel-plan-20260924.json`；仍是模型层覆盖，未扩大GUI验收结论。
