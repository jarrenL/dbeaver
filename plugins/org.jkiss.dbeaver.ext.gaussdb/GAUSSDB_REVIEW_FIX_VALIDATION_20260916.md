# Hermes 审查意见修复与验证（2026-09-16）

基线：`feature/gaussdb-compatibility` / `9354662621`。本文记录在该基线上的本轮修改，不将历史GUI/真库结果冒充本轮复测结果。

## 1. 已修改的内容

| 问题 | 修改方式 | 关键边界 |
|---|---|---|
| 事务任务失败/等待超时后仍终止调试 | UI使用后台Job，不再使用忽略异常和超时结果的`RuntimeUtils.runTask`；只有数据库操作成功返回才调用终止；失败显示“结果未确认”，不自动重试 | 网络断开后的提交可能已经生效，不能声称失败必然回滚；需要独立连接核实 |
| 重复事务事件/收尾并发 | 会话级去重对话框；等待目标JDBC调用及资源释放完成后才开放事务收尾；同一事务锁保护提交、回滚与目标连接关闭 | 取消不等于远程操作已经停止；清理不得并发关闭正在提交的目标连接 |
| 断点注册竞态 | 控制连接统一操作锁，复合查重/删旧/新增保持原子；本地只读列表使用安全快照 | 控制命令执行期间拒绝断点修改；其他短操作之间有界等待，不跨运行状态盲目重放 |
| 步进与栈/变量读取交错 | 控制命令与查询不能同时占用控制连接；发布暂停事件前清除运行标记，允许同步监听器读取新帧；attach资源关闭后才通知暂停 | 忙碌查询明确报错，不用短TTL缓存掩盖旧值 |
| 终止与在途控制命令交错 | 请求取消；仅在控制连接空闲时发送abort，否则关闭连接解除等待；目标事务清理单独协调 | JDBC取消/网络故障的实际响应仍依赖驱动和服务器，需要现场故障测试 |
| 批量编译中断丢失诊断 | 模型层保存不可变的批量结果：诊断、完成数、停止对象、异常/取消状态；UI显示部分结果，不显示整批成功 | 完成数是执行完编译步骤的对象数，不代表每个包都编译无错；源码错误仍在诊断中 |
| 参数默认值、NULL、空串混淆 | 参数表增加输入方式；配置持久化方式列表；保留空串和字面`NULL`；SQL NULL走JDBC空值；默认值通过省略参数交给服务端执行 | 仅省略连续末尾默认参数；需要默认值元数据；同schema存在同名重载时保守拒绝省略，避免运行错误OID |

没有采用：providerId前缀匹配、把空串统一转换成NULL、用Watch短期缓存替代并发协调。复制驱动保留provider，不以此放宽调试资格。

mvn -o verify -f product/aggregate/pom.xml -pl "$review_modules" \
